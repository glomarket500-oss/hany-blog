# 《用心交朋友，才能把订单做完》—— 一段2009年的外贸往事 **作者**：鄭哥 Hany **日期**：2026-09-20 **状态**：✅ 草稿（待核对 3 项资料） --- ## 博客正文 ### 《用心交朋友，才能把订单做完》 ——一段2009年的外贸往事 2009年，广州越秀区江湾公司。我们和德国客户 WTS 的老人机项目，就是从这里开始的。 WTS 的股东是 Frank 和 Dick，他们主要做老人机，市场在德国。合作初期，Frank 派了一名员工到我们公司，一住就是两三个月。那段时间，我也和他一起参与这个项目。他慢慢融入我们当地的文化，跟我们一起开发、一起解决问题。 那时候，诺基亚、爱立信的小手机还没有做到最便宜，深圳山寨机反而很多，三码机、五码机比较多，占领了一部分市场。但客户要求把老人机做到四频，这在当时非常不简单。 为了配合他们，我们采取了很多方案，反复验证，开模也投入了不少钱。配合的工厂在深圳，是陶总的公司。陶总以前从波导出来，那一帮人和后来传音的竺兆江，当年都是同事。双方经过很久的配合，终于把四频老人机方案做了出来。 产品出来后，客户很开心，马上推到德国市场。首批订单是 500K，也就是 50 万台。他们在德国渠道销售，也赚到了钱。直到现在，我们都还在来往。 这段经历，我记下来，不是为了炫耀一个订单。我更想说的是：做外贸，基础就是用心对待每一个客人，用心跟他们交朋友。 客户愿意派人驻厂两三个月，是信任。我们愿意陪着他一起开模、试方案、改产品，是诚意。跨文化融合之后，沟通顺了，再难的产品也能一起做出来。首批 500K 当然重要，但比 500K 更珍贵的，是"现在都还在来往"。 订单是一时的，信任是一辈子的。你真心帮客户解决问题，客户才愿意把订单交给你，甚至愿意和你一起承担开发风险。订单做完不是终点，长期来往才是。 一句话：用心交朋友，才能把订单做完。 这，就是外贸人的基础。 --- ## ⚠️ 发布前需要核对嘅 3 项资料 | # | 核对项 | 重要性 | 建议 | |---|--------|--------|------| | **1** | **WTS 嘅公司全称** | ✅ 高 | 写清楚系「WTS GmbH」、「WTS Telecom」等 | | **2** | **Frank 和 Dick 嘅名字写法** | ✅ 高 | 核对「Frank Müller」、「Dick Schmidt」等 | | **3** | **500K 订单数据** | ⚠️ 中 | 考虑是否适合公开（50 万台订单）| --- ## 📊 文章信息 | 项目 | 详情 | |------|------| | **字数** | ~850 字 | | **结构** | 故事 + 反思 + 金句 | | **调性** | 鄭哥第一人称、外贸老炮儿、有温度 | | **时间锚点** | 2009 年 | | **地点锚点** | 广州越秀区江湾公司 / 深圳工厂 | | **人物锚点** | Frank + Dick + 陶总 + 竺兆江 | | **产品锚点** | 老人机 / 四频 / 500K 订单 | --- ## 🎯 SEO 关键词建议 | 类别 | 关键词 | |------|--------| | **核心** | 外贸故事 / 外贸基础 / 老人机 / 德国客户 | | **业务** | 外贸老炮儿 / 外贸创业 / 2009 年外贸 | | **人物** | Frank / Dick / 陶总 / 竺兆江 / 传音 / 波导 | | **地区** | 广州越秀 / 深圳工厂 / 德国市场 | --- ## 🔗 CTA 建议（文末） ``` 📞 合作联系 WhatsApp: +852 6641 7912 七善門科技 · 星辰算力 ``` --- ## 📝 发布路径 ``` ✅ 草稿：vault\hany博主\文章草稿\2026-09-20-用心交朋友_2009年外贸往事.md ⏳ 待核对：3 项资料 ⏳ 待发布：hany-blog.vercel.app（或 glomarket.vercel.app） ``` --- ## 海哥你嘅下一步 **A** — 帮你核对 3 项资料（WTS 全称 / Frank+Dick 名字 / 500K 是否公开） **B** — 帮你写 SEO meta + 摘要 **C** — 帮你设计发布格式（HTML / Markdown） **D** — 其他 讲我点做，海哥。
